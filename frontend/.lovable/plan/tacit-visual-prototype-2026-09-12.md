
# Tacit visual prototype

## Build
- Replace the blank first page with a full-screen Tacit prototype optimized for calm, high-contrast patient use.
- Add an automatically completing calibration view with an animated circular progress ring.
- Add a timed Yes/No scanner, then a high-frequency needs board using the same highlight and selection feedback.
- Add a frequency-ordered keyboard with scanned letters, an always-available undo action, a composed-message display, and mock selectable phrase suggestions.
- Add a message-confirmed view with an animated speaking indicator and an easy path to start another message.
- Add a separate clinician view switch with denser styling, a continuously updating mock eye-signal chart, threshold line, tracking status, false-activation count, and calibration readouts.
- Keep every interaction simulated locally: Space or click selects the highlighted item; no camera, AI, or audio services.

## Visual system
- Use a dark-mode-friendly clinical palette with soft near-black surfaces, warm white text, reassuring teal, and clear amber focus states.
- Use large typography and stable, spacious targets on patient screens; use compact measurements and chart styling in clinician mode.
- Keep transitions slow and clear, with reduced-motion support and no distracting effects.
- Include the requested prototype disclaimer in a small persistent footer.

## Validation
- Verify calibration auto-advance, timed scanning, keyboard message assembly and undo, suggestions, confirmation, clinician switching, chart motion, and click/Space controls.
- Check desktop and mobile layouts for readable text, non-overlapping controls, and a clean application state.
